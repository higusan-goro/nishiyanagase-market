# デザインの基本値(色・書体・余白)

サイトで使う色・書体・余白の定義。実体は [assets/style.css](../assets/style.css) 冒頭の `:root` にある。
**新しく色や余白を足すときは、まずここにある値を使えないか考える。** 足す場合はここにも追記する。

## 色

| 変数 | 値 | 呼び名 | 主な使いどころ |
|---|---|---|---|
| `--shu` | `#d8332c` | 朱 | 外側の地、赤帯、日付プレート |
| `--shu-dark` | `#a8231f` | 濃い朱 | リンク、英字の小見出し、出店数 |
| `--kinari` | `#f7f0e2` | 生成り | 紙(本文の地)、赤地・墨地の上の文字 |
| `--kinari-deep` | `#efe4cd` | 濃い生成り | 「音楽&パフォーマンス」「開催概要」の地 |
| `--sumi` | `#221e1a` | 墨 | 本文の文字、枠線、フッターの地 |
| `--yamabuki` | `#e0a63f` | 山吹 | ボタンにマウスを乗せたとき |
| `--line` | 墨16% | 罫線 | 一覧の区切り線 |

### 透かし(数字は不透明度%)

| 変数 | 使いどころ |
|---|---|
| `--sumi-12` / `--sumi-22` / `--sumi-25` | 影(チラシ / ボタン・日付プレート / 紙の外枠) |
| `--sumi-30` | 出演者名リンクの下線 |
| `--sumi-65` / `--sumi-66` / `--sumi-70` / `--sumi-72` / `--sumi-78` | 補足の文字(薄い順に) |
| `--sumi-92` | 拡大表示の背景 |
| `--kinari-14` / `--kinari-60` / `--kinari-85` | 墨地の上(閉じるボタン / ハッシュタグ・枠線 / フッター本文) |

**統一候補(未決):** 補足の文字の `65 / 66 / 70 / 72` は見た目にほぼ差がない。
`70` 前後にまとめると扱いやすくなるが、見た目がわずかに変わるため、決めるまでは現状維持。

### チラシとの比較(2026-10-26 抽出)

チラシ表面の画像(`assets/images/flyer-front.jpg`)から、面積の大きい色を拾った値。
画像はJPEGのため多少ぶれる。**サイトの色は変えていない。** 合わせるかどうかは未決。

| | チラシ | サイト | 差 |
|---|---|---|---|
| 赤 | `#ee243e` | `#d8332c`(朱) | チラシの方が明るく鮮やか |
| 生成り | `#fdf6e4` | `#f7f0e2` | チラシの方がわずかに明るい |
| 山吹 | `#f1c181` | `#e0a63f` | チラシの方が淡い |
| 墨 | `#1e1a19` | `#221e1a` | ほぼ同じ |

### 文字と背景の組み合わせ(見やすさの基準、2026-10-27)

ウェブの国際基準(WCAG 2.1 AA)の明るさの差(コントラスト比)で確かめた結果。
ふつうの文字は4.5以上、大きい文字(24px以上、太字は約19px以上)は3以上が必要。

| 文字 / 背景 | 比 | 使ってよい文字 |
|---|---|---|
| 墨 / 生成り | 14.6 | すべて |
| 墨 / 濃い生成り | 13.1 | すべて |
| 生成り / 墨 | 14.6 | すべて |
| 墨 / 山吹 | 7.6 | すべて |
| 濃い朱 / 生成り | 6.3 | すべて |
| 生成り / 濃い朱 | 6.3 | すべて |
| 生成り / 朱 | 4.2 | 大きい文字だけ |
| 朱 / 生成り | 4.2 | 大きい文字だけ |
| 墨 / 朱 | 3.5 | 大きい文字だけ |

- **朱の地には小さい文字を載せない。** 説明文は生成りの地か、濃い朱の地に置く。
- チラシの赤(`#ee243e`)も、白・生成り・墨のどの文字でも4.5に届かない(3.9〜4.2)。
- 色だけで区別しない。ラベルの文字や下線を合わせて使う。

## 書体

| 変数 | 書体 | 使いどころ |
|---|---|---|
| `--mincho` | Shippori Mincho B1(500 / 700 / 800) | 見出し、日付、キャッチコピー、ボタン |
| `--gothic` | Zen Kaku Gothic New(400 / 500 / 700) | 本文 |

どちらも Google Fonts から読み込んでいる。

## 余白・幅

| 変数 | 値 | 使いどころ |
|---|---|---|
| `--sheet-margin` / `--sheet-margin-wide` | 14px / 22px | 赤地と紙の間(スマホ / 720px以上) |
| `--gutter` / `--gutter-wide` | 22px / 56px | 本文の左右余白(スマホ / 720px以上) |
| `--content-width` | 860px | 本文の最大幅 |
| `--section-pad` / `--section-pad-wide` | 58px 0 52px / 74px 0 64px | セクションの上下余白 |

### 画面幅の切り替え(CSSの仕様上、変数にはできない)

- 480px以下: 出店者一覧を1列に
- 720px以上: 余白を広げ、出店者一覧を3列に
- 900px以上: 上部を「文字|イラスト」の2列に
