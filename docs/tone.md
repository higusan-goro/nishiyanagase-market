# 語り口(トーン)

サイトの文章を書く・直すときの基準。第1回のサイトとチラシの文章から抜き出したもの。
迷ったら、下の「お手本」と並べて読み、浮いていないかを確かめる。

## 基本

- **落ち着いた、話しかけるような語り口。** 告知物(チラシ・SNS)と同じ温度で書く。
- 文末は「です・ます」。呼びかけは「〜ください」「〜お待ちしています」とやわらかく。
- 煽らない。「!」「絶対」「必見」「大人気」のような強い言葉や、絵文字は使わない。
- 街への愛着をにじませる。「昼の西柳ヶ瀬」「暮らすように集まろう」のように、
  夜の街という印象を、昼の穏やかな過ごし方で塗り替えていく視点を大切にする。
- 読み手を選ばない。「西柳ヶ瀬をよく知っている方も、初めての方も」の両方に開いておく。

## 言葉づかい

- 地名の表記は本文では「西柳ヶ瀬」「柳ヶ瀬通り5丁目」(小さい「ヶ」)。
- 動作を「〜たり、〜たり」で並べて、過ごし方を想像させる書き方が合う。
- 体言止めは見出しやキャッチコピーで少しだけ。本文は文で書き切る。
- 出店者・出演者の紹介は、名前と扱うものを短く。評価や形容(「絶品」など)は付けない。
- 事実(日時・場所・出店数・名前)は、ゴロが確認したものだけを書く。推測で補わない。

## お手本(第1回の文章から)

> おいしいものを食べたり、気になるものを見つけたり、体験したり、占ってもらったり。
> そして、どこからか聞こえてくる音楽を楽しみながら、街を歩いたり。
> いつもとはちょっと違う、昼の西柳ヶ瀬をお楽しみください。

> 西柳ヶ瀬をよく知っている方も、「西柳ヶ瀬ってどんなところ?」という方も。
> お散歩するような気持ちで、ふらっと遊びに来てください。

> 色々あって西柳ヶ瀬 / そんな歴史のある街。 / 夜だけの街じゃない、 / 暮らすように集まろう。
