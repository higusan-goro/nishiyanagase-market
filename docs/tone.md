# 語り口(トーン)

サイトの文章を書く・直すときの基準。第1回のサイトとチラシの文章から抜き出したもの。
迷ったら、下の「お手本」と並べて読み、浮いていないかを確かめる。

## 基本

- **落ち着いた、話しかけるような語り口。** 告知物(チラシ・SNS)と同じ温度で書く。
- 文末は「です・ます」。呼びかけは「〜ください」「〜お待ちしています」とやわらかく。
- 煽らない。「!」「絶対」「必見」「大人気」のような強い言葉や、絵文字は使わない。
- 街への愛着をにじませる。夜の街という印象を、やわらかく塗り替えていく視点を大切にする。
  昼は「暮らすように集まろう」のような穏やかな過ごし方で、夜は縁日や夜市のように
  個人のお店が並ぶにぎわいとして描く(年2回の開催のうち、1回は昼、1回は夜(19時ごろまで)の回にする想定。2026-10-27)。
- 読み手を選ばない。「西柳ケ瀬をよく知っている方も、初めての方も」の両方に開いておく。

## 言葉づかい

- 地名の表記は「西柳ケ瀬」「柳ケ瀬通5丁目」(大きい「ケ」)。岐阜市や補助金の手引きと同じ表記にそろえる
  (2026-10-27 決定。第1回のサイトとチラシは小さい「ヶ」だったが、第2回から切り替える)。
- 「晴れの日」ではなく「ハレの日」と書く。
- 街の夜の顔に触れるときは「夜だけの街じゃない」の方向で言う。行政とも連携するため、
  差別的と受け取られうる言葉は使わない。
- 動作を「〜たり、〜たり」で並べて、過ごし方を想像させる書き方が合う。
- 体言止めは見出しやキャッチコピーで少しだけ。本文は文で書き切る。
- 出店者・出演者の紹介は、名前と扱うものを短く。評価や形容(「絶品」など)は付けない。
- 事実(日時・場所・出店数・名前)は、ゴロが確認したものだけを書く。推測で補わない。
