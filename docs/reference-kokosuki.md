# 手本のサイトの読み解き(こすぎるまちフェス)

第2回のサイトの構成・寸法の手本。2026-10-27、ゴロの判断で参考サイトをこの1つに絞った。
https://kokosuki.studio.site/ (総合トップ)・https://kokosuki.studio.site/2026 (各回のページ)

取り入れるのは**構成・寸法・部品の形**だけ。ロゴ・文言・イラスト・キャラクターは写さない。
色は西柳ケ瀬のチラシ(朱・生成り・墨・山吹)に置き換える。

## 全体の構成(2層)

| 層 | 手本 | 西柳ケ瀬 |
|---|---|---|
| 総合トップ | `/` ABOUT/NEXT EVENT/ARCHIVE/SNS/CONTACT | `index.html` |
| 各回のページ | `/2026`・`/2024` | `2027-05/`(第2回)。第1回は `2026-10/`(当時の告知ページを固定したもの) |

回を重ねても、総合トップは「次の開催」と「これまでの回」のカードを差し替えるだけで済む。

## 総合トップ(寸法はパソコン幅1280px/スマホ幅375pxで測った値)

- **地:** ページ全体が1色(手本は黄 #fff57f)。→ 朱。本文は必ず生成りのカードの中に置く(朱の上は大きい文字だけ)
- **メニュー:** 右上に固定した白い角丸のピル(枠2px・角丸128px)。スマホは「メニュー」ボタン1つ
- **看板:** 高さ約720px。大きな丸の模様の地+中央に大きなロゴ+右下に丸い開催バッジ
  → 朱の地に生成りの丸の模様、チラシのイラスト、「第2回 2027.5 下旬に開催予定」のバッジ
- **見出し:** 中央に大きな英字(48px/スマホ36px・極太)+下に日本語(16px)。上の余白128px
  → 英字は同じ。日本語は朱の上でも読めるよう20pxの太字に
- **カード:** 幅768px、枠4px、角丸24px、内側の余白84px(スマホ44px)
- **本文:** 24px(スマホ18〜20px)、行間1.8、太め → 70代の方にも読みやすい大きさなので、そのまま採用
- **カードの中の白い囲み:** 角丸8px(手本:「㋙ってなに?」)→「西柳ケ瀬って、どんな街?」
- **画像入りカード:** 上に横長の画像(約1.9:1)、下に本文、右下に「→ 詳細を見る」
- **区切り:** 白い6pxの線+24pxの小見出し(手本:「イベントレポート」)→「第1回の様子」
- **ラベル付きの写真カード:** 左上にタブ状のラベル(手本:REPORT・INTERVIEW)→ にぎわい・出店者・流し など
- **SNS・CONTACT:** 白いカード、上に6pxの色線。主催などは黒いピルのラベル。右下に薄いすかし
- **著作表示:** カードの外、右寄せ14px

## 各回のページ(手本:/2026)

- **地:** トップと別の淡い色(手本は桃色)→ 濃い生成り
- **パソコン:** 左半分にロゴと日付を固定し、右半分のカード(幅492px)だけがスクロールする
- **カードの右に縦書きの英字ラベル**(EVENT・CONTENTS・PRESENT・DETAILS など)
  → スマホでは本文の幅を確保するため、カードの上に横書きで置く(手本と違う点)
- **導入文:** 24pxの太字で3段落
- **コンテンツカード:** 番号(01〜05)+見出し+本文+「→ 詳細はこちら」。カードごとに地の色を変える
  → 01おいしいもの/02手仕事と買いもの/03やってみる/04占ってもらう/05音楽とパフォーマンス。
    カードの中に出店者の一覧を入れる(手本は別ページへ飛ぶ)
- **表:** 1pxの線で区切った「項目|内容」の行(手本:ノベルティ・開催概要)→ ご来場のみなさまへ・開催概要
- **ページの終わり:** 目次カード(英字+日本語を6pxの線で区切る)、ハッシュタグ、SNS、CONTACT

## 動き

手本(STUDIO製)はカードが画面に入ったときに出てくる程度。→ 画面に入ったとき一度だけ下からふわっと出す。
動きを減らす設定の人には動かさない。
