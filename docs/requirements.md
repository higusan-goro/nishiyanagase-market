# やりたいこと・決まったこと

西柳ケ瀬ストリートマーケット特設サイトの方針置き場。
**チャットで決めたことは、実装する前にここに書く。** 書いてから手を動かす。

> このリポジトリは公開設定のため、このファイルもGitHub上では誰でも読める。
> 出店者との交渉内容・個人情報・未発表の情報はここに書かない。

## サイトの位置づけ

- 2026年10月4日に第1回を開催した「西柳ケ瀬ストリートマーケット」の特設サイト。
- 単発の制作物ではなく、**回を重ねるごとに育てるサイト**として扱う。
- 次回(第2回)は2027年5月下旬開催予定。

## 決まったこと

### 2026-10-26 ファイル構成の整理

- index.html 1枚にすべて埋め込まれていた画像・CSS・JSを分ける。
  - 画像 → `assets/images/`(base64をやめて実ファイルに)
  - CSS → `assets/style.css`、JS → `assets/script.js`
  - 色・書体・余白をCSS変数に整理(定義は [design-tokens.md](design-tokens.md))
- 条件: **見た目は1pxも変えない。** 作業前後のスクリーンショットを
  スマホ(375px)・タブレット(768px)・PC(1280px)と拡大表示で比べ、差分0を確認してからコミットする。
- 画像はこの段階では圧縮しない(圧縮すると見た目が変わるため)。圧縮は別の機会に検討する。
- SNSでシェアしたときの画像(OGP)がbase64で書かれていて表示されていなかったため、
  チラシ表面の画像の完全なURLに直す(見た目は変わらない、別コミット)。

### 2026-10-26 文書と道具の扱い

- `docs/`(この文書類)と `tools/`(確認用の道具)は、**Webページとしては公開しない**
  (`_config.yml` で除外)。
- 役割ごとのサブエージェントを3つ置く(`.claude/agents/`)。
  - `content-writer` … 文章の執筆・改稿。語り口は [tone.md](tone.md) に従う
  - `designer` … レイアウト・配色・余白の判断。チラシの世界観から外れないか見る
  - `reviewer` … 実装後の点検(表示崩れ・リンク切れ・スマホ幅・読み込み速度)。
    見つけた問題は [changelog.md](changelog.md) に記録し、回をまたいで振り返る
  - 必要になったら足す。

### 2026-10-26 過去の回の残し方

- **終わった回の告知ページは、日付のフォルダに丸ごと固定して残す。**
  第1回は `/2026-10/`(https://higusan-goro.github.io/nishiyanagase-market/2026-10/)。
  - そのフォルダ専用のCSS・JS・画像を持たせ、新しいデザインの変更が及ばないようにする。
  - 固定したあとは中身を変えない。例外は、記録であることを示す注記の帯(ページ上部に1本)と、
    ページ名・SNS用画像のURLだけ。
  - 帯の文面: 「このページは、2026年10月4日に開催した第1回の告知を、記録として残したものです。」
    と、最新の開催へのリンク。
- トップページ(`/`)は、第2回のデザインができるまで第1回のまま。新しいデザインの公開時に入れ替える。
- 第2回以降も、回が終わったら同じ手順で固定する(手順は README)。
- 「当時の告知ページ」とは別に、「第1回はこうだった」という振り返りを新しいサイトに載せるかは壁打ちで決める。

### 2026-10-27 第2回のサイトの土台(壁打ちで決まったことのうち、外に出してよいもの)

- **読み手:** 不特定多数。40代以上を基本に、70代の方にも見やすいユニバーサルデザインにする。
  本文は16px以上、注記も14px以上を目安にする。
- **読んだ人にしてほしいこと:** 当日来る → 知り合いに教える → Instagramをフォローする、の順。出店者の募集はサイトでしない。
- **言葉:** 目指す姿は「通り過ぎる道を、歩きたくなる商店街へ」。呼びかけは「西柳ケ瀬で、また会いましょう。」。
  表記は「西柳ケ瀬」「ハレの日」。語り口の詳細は [tone.md](tone.md)。
- **骨組み:** 2026-10-27 に手本を「こすぎるまちフェス」1つに絞った(読み解きは [reference-kokosuki.md](reference-kokosuki.md))。
  - 総合トップ(`index.html`):ABOUT/NEXT EVENT/ARCHIVE/SNS/CONTACT。地は朱、本文は生成りのカードの中。
  - 各回のページ:第2回は `2027-05/`。出店者・出演者・お願い・開催概要・チラシ・協賛はこちらに置く。
    パソコンでは左にイラストと日付を固定し、右のカードだけがスクロールする。
  - 総合トップの調整(2026-10-27 ゴロ):カードの左右の余白を半分に(幅は「画面の半分+384px」)。
    「次の開催」は大きく見せ、カード全体と看板のバッジを押すと第2回のページへ移る。「西柳ケ瀬で、また会いましょう。」は赤で目立たせる。
    看板のイラストは、下段の3人(子ども・女性・男性)を外して大きく見せる(`assets/images/hero-top.png`)。
    第1回の数字(来場者数・出店数・アンケート)はトップに出さない。
  - 全体の見直し(2026-10-27、複数の視点での評価をもとにゴロが決定):
    - 配色はチラシと同じ配分にする(生成りの紙が主、朱は外側の額縁とアクセントだけ)。地紋はチラシの星・音符・赤い曲線。
    - 看板は、広い画面では「文字|イラスト」の2列。何の市か・いつ・どこ・だれでも、を最初の画面に出す。
    - 見出しは日本語を主役に、英字は小さく添える。日付・数字・ひとことは太い明朝(チラシの日付と同じ)。
    - 「知り合いに教える」(LINEで送る・このページを送る・チラシを保存する)、昼の回と夜の回の打ち出し(年2回のうち1回は昼、1回は夜で19時ごろまで。第2回は昼の回)、Googleマップへのリンク、
      検索結果用の開催情報(日にちが決まったら `2027-05/index.html` の startDate を書き換える)を足す。
    - 第1回の写真を「東柳ケ瀬から西柳ケ瀬へ」流れる帯にする。SNS・お問い合わせは最後の墨の帯にまとめる。
    - 広い画面の左右の余白に昭和3年のスズラン灯を並べ、読み進めるほど1つずつともす(動きを減らす設定では切り替えのみ)。
  - 出店者は、各回のページのコンテンツカード(01おいしいもの〜05音楽)の中に「名前+扱うもの+Instagram」の一覧で並べる。
- **色:** 赤は「面」と「大きい文字」だけに使い、小さい文字は載せない(詳細は [design-tokens.md](design-tokens.md))。
  面の赤は今の朱(`#d8332c`)のまま。チラシの赤より少し落ち着いた色で、並べても別物に見えない。
- **動き:** 参考サイトの範囲で入れるが、読みやすさ・軽さを優先する。
- **公開先:** GitHub Pages のまま。地域イベントの告知・記録のサイトなので、GitHubの規約(商取引が主目的のサイトの禁止)に当たらない。
  グッズの予約・販売はサイトの中では受け付けず、外のフォームなどにリンクする。
- **アクセス数:** 無料の計測ツールで毎月計り、総アクセス数をサイトに表示する。
- **お問い合わせ先:** 引き続き樋口のメールアドレス。運営メンバーは名前まで載せ、顔は出さない。
- **運用:** 確定した情報はサイトが最初に全部出し、Instagramは近づく気配を伝える。更新は1人で回せる形にする。
- **マーケットが終わっても**、サイトは記録として残す。

### 2026-10-27 第2回のサイトづくりの始め方

- 新しいサイトは、ブランチ `dai2kai`(下書き用の枝)で作る。公開中のトップページ(第1回)は、ゴロが了承するまで変えない。
- 1回目に作る範囲:総合トップ、第2回のページ(`2027-05/`)、「西柳ケ瀬の歩み」のページ(`history.html`)。
- 「次回」の中身は、第2回の内容が決まる(2月ごろ)まで第1回のものを仮に入れる。下書きの画面には「仮の内容」の帯を付け、公開前に外す。
- 出店者カードは、ロゴが集まるまで店名とジャンルの文字だけで作る。
- 今回は作らないもの:グッズ、出店者向け素材のダウンロード、アクセス数の表示、バリアフリー情報、補助金の表記(中身が決まりしだい差し込む)。
- **写真:** イラスト化(線画・描き起こし)はしない。第1回の当日の写真をそのまま使う(写っている人の掲載許可は取得済み)。
  - 選ぶ写真:引きで撮った、にぎわいが伝わる写真/出店者の写真で、楽しさがひと目で分かるもの。
  - 載せるときは、レイアウトを崩さないように加工する(大きさ・圧縮をそろえる)。そのままで違和感があるときは、
    トリミング・部分的な切り抜き・背景の透過をする。
  - 元の写真(約160枚)はこのリポジトリに入れず、加工して使うものだけを `assets/images/photos/` に置く。
- チラシのイラストは、チラシの描き手の作品としてそのまま使う(新しく描き起こしはしない)。
- 『柳ケ瀬百年誌』の写真・絵は使わない(文章の事実だけを使う)。

## 進め方のルール

- 1コミット1目的。コミットメッセージは日本語でよい。
- 変更はローカルで表示確認してから push する。公開中のサイトをいきなり壊さない。
- 画像を足すときは必ず圧縮する。ページ全体で1MBを超えそうなら相談する
  (2026-10-26時点で、ページ全体は約0.7MB)。
- サイトの文章は、告知物(チラシ・SNS)と同じ落ち着いた語り口を保つ([tone.md](tone.md))。
